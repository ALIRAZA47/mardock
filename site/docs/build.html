MarDock has no dependencies: it builds with SwiftPM, using Xcode 15 or later (Xcode 26 for Liquid Glass) or just the Command Line Tools.

Build and run

git clone https://github.com/ALIRAZA47/mardock.git
cd mardock
make install    # builds, copies to /Applications and opens MarDock

Or use make run to build and launch from build/MarDock.app without installing.

Checks

make test       # unit tests: engine, validation, protocol
make audit      # security audit of the built app
make selftest   # end-to-end checks against your system
make playground # the dock in your browser

CI runs the same tests, build, audit and self-test on every change, then takes screenshots and records a tour of the dock on a macOS runner.

Finding your way around

PathWhat's there
Sources/MarDockCore/Pure Swift: spring physics, the magnification warp, the layout engine, validated settings and the helper protocol. Unit-tested, and also builds on Linux.
Sources/MarDock/The sandboxed app: the Core Animation renderer, app state, and the SwiftUI settings.
Sources/MarDockAgent/The XPC helper.
Sources/MarDockUpdater/The sandboxed updater, the only part with network access.
playground/A browser port of the engine and themes, which is also this site's live demo.
site/This site, built with python3 site/build.py.

The interesting part is DockEngine: it owns every spring and produces one frame per display refresh. The magnification maths is in Magnifier.

Signing for distribution

Local builds are signed ad-hoc, which is fine on the Mac that built them. To share MarDock, sign it with a Developer ID and notarize it:

SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" make app
ditto -c -k --keepParent build/MarDock.app build/MarDock.zip
xcrun notarytool submit build/MarDock.zip --keychain-profile <profile> --wait
xcrun stapler staple build/MarDock.app
make dmg
