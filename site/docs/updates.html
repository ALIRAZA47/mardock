Nothing updates unless you ask, and your whole dock fits in one file.

Updates

Choose Check for Updates… in the menu bar menu, or use the Updates section in Settings ▸ General or About. You can also turn on Check for updates once a day, which is off by default.

Checking asks GitHub for MarDock's newest release and sends nothing about you. A separate, sandboxed part of MarDock does it, so the dock itself stays offline.

What installing does

  1. The updater downloads the release and checks it against its published checksum.
  2. MarDock's helper checks it again, along with its signature and version.
  3. The helper swaps the app, and MarDock relaunches as the new version.

If MarDock isn't in your Applications folder, it can't replace itself. Move it there, or download the update yourself.

Releases are signed ad-hoc for now, so after an update you'll need to allow Accessibility and Screen Recording again if you use them.

Move to another Mac

Export Settings… in Settings ▸ General saves your dock, settings, themes, profiles, shortcuts and custom icons in one file. Import Settings… on the other Mac replaces them.

Some choices belong to each Mac, so importing leaves them alone: whether MarDock hides the macOS Dock, which display it uses, and the extras. A file can never turn on something that uses a permission.
