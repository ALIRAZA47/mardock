It takes about a minute. You need macOS 14 Sonoma or later, on Apple silicon or Intel.

Download

  1. Download MarDock-{{version}}.dmg.
  2. Open it and drag MarDock to Applications.
  3. Open MarDock from Applications.

Older versions, the zip and the checksums are on the Releases page.

If macOS can't verify it

Releases are signed ad-hoc and not notarized for now, so the first time you open one, macOS says it can't verify MarDock.

  1. Click Done.
  2. Open System Settings ▸ Privacy & Security and scroll down to the notice about MarDock.
  3. Click Open Anyway. You only do this once.

Or clear the download flag before you open it:

xattr -dr com.apple.quarantine /Applications/MarDock.app

Check your download

Each release lists SHA-256 checksums and a build provenance, which proves the file was built by this repository's release workflow from that version's tag.

shasum -a 256 -c SHA256SUMS.txt --ignore-missing
gh attestation verify MarDock-{{version}}.dmg --repo ALIRAZA47/mardock
