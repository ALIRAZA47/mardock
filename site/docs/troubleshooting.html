If none of this helps, report a bug with your macOS and MarDock versions. You'll find those in Settings ▸ About.

I can still see the macOS Dock

  1. Check that Replace the macOS Dock is on in Settings ▸ General. The tile says whether it's hidden.
  2. Make sure you're on version 1.2 or later. Earlier versions missed two ways the Dock could come back.
  3. Check that MarDock is running. Quitting it restores the Dock, unless you've turned that off.

I've got no dock at all

MarDock isn't running, and the macOS Dock is still hidden. Open MarDock with Spotlight, or follow Getting it back.

MarDock doesn't open at login

  1. Check that Open at login is on in Settings ▸ General.
  2. If it says macOS is waiting for your approval, choose Open Login Items… and allow MarDock.
  3. Make sure MarDock is in your Applications folder, so it's still there at your next login.

Badges, minimized windows or previews stopped working

That usually means an update reset the permission. Open Settings ▸ Extras, which says what's missing, and allow MarDock again in System Settings.

The shortcuts panel doesn't show an app's commands

Reading them needs Accessibility: use Allow… in Settings ▸ Shortcuts. Some apps have nothing to show, because their third menu isn't a File menu or has no New or Open commands. The rest of the panel still works.

macOS can't verify MarDock

That's expected for releases signed ad-hoc. Follow the Open Anyway steps.

Windows go under the dock

macOS doesn't let other apps reserve screen space. Set Automatically hide to When a window overlaps in Settings ▸ Behaviour.

Removing MarDock

  1. Quit MarDock from its menu bar icon, which restores the macOS Dock.
  2. Move MarDock from Applications to the Trash.
  3. To remove your settings too, delete ~/Library/Containers/io.github.aliraza47.MarDock.
